# Be The Buzz & Co.

**Paid media scripts for Google Ads, Microsoft Advertising, and more.**

We're a California-based paid media agency. This is where we share the automation scripts we use to manage client accounts: reporting, budget pacing, bid checks, and alerts.

## What you'll find here

- **Google Ads Scripts** (JavaScript, run in Tools > Bulk actions > Scripts)
- **Microsoft Advertising Scripts** (run in Tools > Scripts)
- Setup notes and config options at the top of every script

## How to use a script

1. Open the script file and copy the code.
2. Paste it into your ad platform's Scripts editor.
3. Update the config section (emails, thresholds, sheet URLs).
4. Click **Preview** first, review the log, then authorize and schedule.

## Disclaimer

Scripts are provided as-is. Always preview and test in your own account before scheduling. Review any script that makes changes (bids, budgets, pausing) before running it live.
